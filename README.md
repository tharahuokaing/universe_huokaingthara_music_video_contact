## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_music_video_contact`** provides a dedicated contact and production inquiry desk for the music video division of **UNIVERSE HUOKAING THARA Group**. Visitors can filter inquiry desks, search topics live, pre-fill the contact form from any desk card, and generate a reference receipt (`UHT-MV-XXXXXX`) with clipboard copy support upon submission.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🔎 Live Search & Desk Filtering:** Filter inquiry desks (*Production, Artists & Audio, Promo & Media*) or search keywords and topics in real time.
* **⚡ One-Click Topic Pre-Fill:** Select a desk topic to automatically set the inquiry dropdown and smooth-scroll to the contact form.
* **🧾 Confirmation Receipt & Reference Copy:** Generates a reference code upon form submission with one-click clipboard copy support.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.
